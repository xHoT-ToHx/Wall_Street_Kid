# 번역 스타일 가이드 — Wall Street Kid (영어 → 한국어)

사용자 확정(2026-11-16): 종목명은 실제 회사명 영문 표기 / 말투는 캐릭터별 차등 / 그 외 고유명사는 전부 한글 음역.

## 화면 제약 (scripts/README.md 가 정본)
- 대사창: 줄당 28칸, 6줄. 한글 1자 = 1칸, 영문·숫자·기호·공백 = 1칸.
- 줄은 27칸 이하 + 줄바꿈을 원칙으로 한다(28칸 꽉 채운 뒤 줄바꿈은 빈 줄이 생길 수 있음 — 미확인).
- 한 페이지(<PAGE> 사이)는 6줄 이내. 넘치면 <PAGE> 를 추가하지 말고 문장을 줄인다(제어코드 개수·순서는 원문과 동일하게 유지).
- 한 페이지에 쓰는 **서로 다른 한글 음절은 90자 이내**를 목표로 한다(타일 예산, 엔진 확정 뒤 수치 조정 예정).
- 고정폭 문자열(메뉴·요일·상태창·매매 화면 틀·종목명)은 원문과 같은 칸 수 이내. 열 정렬용 공백은 유지.

## 종목명
- 패러디명(YBM, BOING …)은 쓰지 않고 glossary.tsv 의 실제 회사명을 **영문 대문자**로 적는다. 한글 조사는 바로 붙인다(예: "IBM이", "BOEING의").
- 종목 뉴스의 말장난 농담은 패러디 철자에 의존하므로 직역하지 않는다. 회사의 업종·실제 이름을 소재로 한 가벼운 농담으로 의역하고, 끝맺음 "하! 하! 하!" 의 분위기를 유지한다.

## 표기
- 금액: `$` 와 아라비아 숫자 유지($1,000,000). "달러"로 풀어 쓰지 않는다. <VAR> 주변 어순은 한국어에 맞게 조정하되 토큰은 유지.
- 숫자: 아라비아 숫자.
- 허용 문자: 한글, 영문 대문자, 숫자, 원문 테이블에 있는 기호만 — ( ) ' " , $ ! ? - : … . / % &. 소문자·물결(~)·가운뎃점·낫표는 폰트에 없으므로 쓰지 않는다.
- 외래어: 국립국어원 표기법, glossary 우선.
- 미국 문화 요소(메모리얼 데이 등)는 음역/통용 번역을 쓰고 설명을 덧붙이지 않는다.
- 유머·과장된 어조가 원작의 맛이므로 딱딱한 직역보다 자연스러운 구어체를 우선한다.
