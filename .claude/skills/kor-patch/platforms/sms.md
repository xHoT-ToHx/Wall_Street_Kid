# SMS (세가 마크 III / 마스터 시스템) · GG (게임 기어)

## 하드웨어 요점
- CPU Z80. Sega 매퍼: $FFFC-$FFFF 레지스터로 16KB 슬롯 3개($0000/$4000/$8000) 매핑. 첫 1KB 는 고정.
- 타일: **4bpp, 행마다 plane0..3 순서 4바이트** (`sms4bpp`), 32B/타일. VRAM 16KB 중 타일 영역 ≈ 448타일(이름테이블/스프라이트 제외).
- VRAM 접근은 VBlank 중 또는 디스플레이 off 시. 프레임당 전송량 제한적.
- 헤더 "TMR SEGA" @ $7FF0. 해외판 SMS BIOS 는 체크섬 검사, 일본 Mark III / GG 는 미검사. `romkr build` 가 수정.
- GG 는 화면 160x144 (타일맵의 일부 창) → 대사창 폭이 좁음.

## 주소 변환
- 2바이트 LE 포인터 + 슬롯2($8000) 뱅크: `{"type":"linear","cpu_base":"0x8000","file_base":"bank*0x4000","window":"0x4000"}`
- 슬롯1($4000) 사용 게임은 cpu_base 0x4000.

## 텍스트 엔진 특징
- 1바이트 코드, 8x8 셀. 폰트가 1bpp/2bpp 로 압축 저장되었다가 4bpp 로 확장되는 경우 다수.

## 한글 폰트 전략
1. 8x16 한글 + 동적 로딩 (대사창 줄 수 절반).
2. 타일 여유가 충분하면(메뉴 화면 등) 빈도 상위 글자 상주.
3. GG 는 폭이 좁아 16x16 은 줄당 9자 이하 — 번역가에게 제약 강하게 전달.

## 도구
- 어셈블러: WLA-DX (z80). 디버거: Mesen2(SMS/GG 지원 여부와 memory_type 은 emucap `status` 로 확인) 또는 Mednafen 포크.
