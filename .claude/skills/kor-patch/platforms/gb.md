# GB (게임보이) · GBC (게임보이 컬러)

## 하드웨어 요점
- CPU SM83(LR35902, Z80 유사). 롬 bank0 $0000-$3FFF 고정, $4000-$7FFF 스위칭(16KB). MBC1/2/3/5 종류에 따라 최대 뱅크 수가 다름(헤더 $147).
- 타일: **2bpp, 행마다 plane0, plane1 교차** (`gb2bpp`), 16B/타일. VRAM 타일 384개(GB), GBC 는 2뱅크라 768개.
- VRAM 접근은 모드 0/1(HBlank/VBlank) 중만. GB 는 프레임당 전송량이 매우 작음, GBC 는 HDMA/GDMA 사용 가능.
- 헤더 체크섬($14D)은 부팅 시 검사(틀리면 부팅 불가), 글로벌 체크섬($14E)은 미검사. 둘 다 `romkr build` 가 수정.
- GBC 전용/겸용 플래그 $143 (0xC0 전용, 0x80 겸용).

## 주소 변환
- 2바이트 LE 포인터 + 뱅크 N: `{"type":"linear","cpu_base":"0x4000","file_base":"N*0x4000","window":"0x4000"}`
- bank0 텍스트: `{"type":"linear","cpu_base":"0","file_base":"0","window":"0x4000"}`
- 3바이트(뱅크+주소) 포인터는 뱅크 바이트를 별도 테이블로 처리하거나 asm 쪽에서 재설계.

## 텍스트 엔진 특징
- 1바이트 가나, 8x8 셀, 탁점 윗줄 방식 다수. 화면 20x18 타일 → 대사창 줄당 16~18자.

## 한글 폰트 전략
1. **8x16 또는 16x16 한글 + 동적 로딩**이 사실상 필수(상주 타일 부족). 대사창 2~3줄.
2. GB(흑백)는 VBlank 전송량이 작아 "한 글자씩 출력" 연출과 맞춰 매 프레임 1~2글자 업로드.
3. GBC 겸용 롬은 GBC 모드에서 VRAM 뱅크1 을 폰트 전용으로 쓰는 방법도 있음(GB 모드 호환 주의).

## 확장
- MBC1 최대 2MB(125뱅크, 일부 뱅크 사용불가), MBC3 2MB, MBC5 8MB. 확장 시 $148 갱신.

## 도구
- 어셈블러: rgbds. 디버거: Mesen2 (emucap).
